# UC1 integration contracts

The authoritative contract set is `contracts/integration/uc1_integration_contracts.yaml`. It covers T4.4, T4.2, T4.5, T3.3, T3.4, T3.5, T3.1/T3.6, and WP6/NRW.

Stable concepts are UC1 IDs, versioned schemas, event/reference fields, requested-versus-applied actions, timestamps, source status, missingness, and fail-closed outcomes. API transport, authentication, deployment, standard message profiles, and partner-specific fields remain proposed or TBD. Changes require a schema version and migration note.
