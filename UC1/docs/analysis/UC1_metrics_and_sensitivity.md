# UC1 metrics and sensitivity

Metrics distinguish generated and observed attacks, detected message IDs, controller effects, safety violations, unauthorized disclosure, evidence capture, integrity failures, and loss causes. Null means the denominator is undefined.

The predeclared 100-sample design varies channel loss, observation coverage, jitter, and detection threshold. It reports 95% normal-approximation intervals as a compact synthetic analysis. It does not estimate real Car2X performance or proposal KPI attainment.
