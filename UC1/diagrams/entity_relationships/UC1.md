# UC1 entity-relationship model

The detailed readable projection is maintained in `UC1_entity_relationships.md`. The authoritative model is the pair `models/instances/uc1_entities.json` and `models/relationships/uc1_relationships.csv`; `models/graph/uc1_graph.json` is its validated deterministic projection. This file preserves the exact artefact name required by `readme_UC1.md` and prevents consumers from treating the explanatory diagram as a second source of truth.
