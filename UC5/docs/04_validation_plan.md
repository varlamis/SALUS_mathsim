# UC5 validation plan

Validation proceeds in gates: strict schema/config and prohibited-field checks; ID, relation, twin and BPMN integrity; deterministic baseline/nominal execution; clinical-continuity, privacy and truth-isolation invariants; loss, backup, enforcement, health-fault and sharing branches; evidence/custody verification; graph queries; 100-sample uncertainty analysis; integration contracts; automated tests; and final SHA-256 manifest verification. Any essential-monitoring interruption, patient-data disclosure, hidden-truth leakage or unauthorized sharing is a release blocker.
