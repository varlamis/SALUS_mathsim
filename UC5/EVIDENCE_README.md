# UC5 Evidence Package

UC5 supports the clinical-continuity-aware medical IoT monitoring scenario.

Key evidence:

- `models/` records the canonical entities, relationships, schemas, graph, and
  formal model.
- `configs/uc5/` defines the baseline, compromised-monitor, experiment, and
  Monte Carlo runs.
- `docs/` and `diagrams/` describe the assumptions, process views, graph
  queries, integration boundaries, and validation plan.
- `src/` contains the executable flow, evidence, policy, and analysis
  implementation.
- `tests/` contains the retained automated tests and fixtures.
- `reports/generated/uc5/` contains nominal and baseline metrics, experiment
  comparisons, Monte Carlo summaries, run manifests, evidence manifests, and
  validation reports.
- `reports/final/` contains the final handoff and artifact manifest.
