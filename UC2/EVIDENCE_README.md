# UC2 Evidence Package

UC2 supports the passive IoT observation and privacy-bounded classification
scenario.

Key evidence:

- `models/` records the canonical entities, relationships, schemas, graph, and
  formal model.
- `configs/uc2/` defines the baseline, unapproved-device, experiment, and Monte
  Carlo runs.
- `docs/` records the source-governed case, assumptions, process notes,
  graph queries, and validation plan.
- `src/` contains the executable implementation used to generate the reported
  metrics.
- `tests/` contains the retained test suite and schema fixtures.
- `reports/generated/uc2/` contains nominal and baseline metrics, experiment
  comparisons, Monte Carlo summaries, run manifests, evidence manifests, and
  validation reports.
- `reports/final/` contains the final handoff and artifact manifest.
