# UC2 end-to-end processes

1. Validate scope, configuration, identifiers and passive-only boundary.
2. Emit abstract device-interface observations and apply coverage, loss and queue capacity.
3. Normalize and pseudonymize before association.
4. Associate observations inside the configured window and emit alternatives.
5. Classify the hypothesis with confidence and missingness; query registry state.
6. Alert only for an observable unapproved hypothesis above threshold.
7. Record requested and applied bounded response separately; never perform RF action.
8. Project allowlisted evidence fields, hash, custody-link and verify them.
9. Reconstruct from verified evidence only and export loss/ambiguity limitations.
