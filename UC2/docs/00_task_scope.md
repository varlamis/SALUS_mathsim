# UC2 task scope

UC2 models one passive synthetic device-detection vertical slice. Abstract
3GPP, Wi-Fi and BLE observers produce pseudonymized metadata. Association,
classification, registry lookup, explainable alerting, bounded review, evidence
and reconstruction operate without live interfaces or personal identifiers.

Proposal facts, engineering decisions, synthetic defaults and open expert values
remain distinct. DS2 and DS3 are future import boundaries, not model inputs.
