# UC2 integration contracts

The authoritative contract set is `contracts/integration/uc2_integration_contracts.yaml`. Eight versioned boundaries cover observer-to-association, association-to-classification, classification-to-detection, registry lookup, alert-to-policy, twin output to T4.4, evidence to forensic services, and run evidence to T4.5/WP6.

Stable concepts are UC2 identifiers, canonical timestamps, pseudonyms, observation references, alternatives, requested/applied action separation, evidence hashes and explicit missingness. Transport, authentication, deployment endpoints, real radio adapters, partner-specific fields and dataset mapping remain proposed/TBD. No contract authorizes interception, transmission, deauthentication or device attribution to a person.
