# UC3 Evidence Package

UC3 supports the industrial cyber-physical surrogate scenario, where response is
constrained by process safety.

Key evidence:

- `models/` contains the canonical entities, relationships, schemas, graph, and
  formal model.
- `configs/uc3/` defines the smart-fuzzing nominal run, experiment matrix, and
  Monte Carlo configuration.
- `diagrams/` and `docs/` provide process, lifecycle, assumption, and validation
  evidence.
- `src/` contains the executable simulator and analysis code.
- `tests/` contains retained validation, simulation, graph, contract, and
  handoff tests.
- `reports/generated/uc3/` contains metrics, experiment comparisons, Monte
  Carlo summaries, run manifests, evidence manifests, and validation reports.
- `reports/final/` contains the final handoff and artifact manifest.
