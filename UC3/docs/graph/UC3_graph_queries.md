# UC3 graph queries

The runtime graph answers physical entity/twin membership, PLC attacker/observer paths, evidence sources, and assumption status. Extensions must add queries for process influence paths, mitigation constraints, claim support/contradiction, stale twins, integration consumers, and source status.

Queries traverse stable IDs and typed edges. `models/graph/uc3_graph.json` is generated from canonical JSON/CSV and contains their SHA-256 digests.
