# UC3 integration contracts

Eight contracts cover T4.4, T4.2, T4.5, T3.3, T3.4, T3.5, T3.1/T3.6, and WP6/UkrNS/FIMOI. Stable concepts are IDs, versions, units, timestamps, source status, missingness, requested/applied actions, evidence integrity, and fail-closed errors.

Transport, authentication, production APIs, exact industrial protocols, datasets, and pilot calibration remain proposed/TBD. Changes require schema versioning and migration notes.
