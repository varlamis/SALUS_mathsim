# UC3 process model

The causal sequence is initialization → warm-up/normal scans → symbolic reconnaissance/fuzzing → validation → detection/explanation → safety-constrained policy → abstract enforcement/recovery → evidence/custody → reconstruction/evaluation.

Process observations occur independently from attack messages. Mitigation records requested, applied, effective, and live-enforcement status separately. Reconstruction consumes only evidence; evaluation truth is used afterward for metrics. BPMN files are editable process views and must agree with formal state transitions.
